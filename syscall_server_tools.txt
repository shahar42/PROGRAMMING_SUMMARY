search_syscalls(query, limit=10) - Search by name/functionality

Example: search_syscalls("epoll") finds epoll_create1, epoll_wait, etc.


get_syscall_details(syscall_name) - Complete reference for one syscall

Example: get_syscall_details("fork") shows synopsis, parameters, return values, all error codes


find_related_syscalls(syscall_name) - Cross-reference related calls

Example: find_related_syscalls("fork") shows exec, wait, etc.


list_syscalls_by_category() - Browse by functional groups

Shows File Operations, Process Management, Network/Socket, etc.


lookup_error_code(error_code) - Reverse lookup what syscalls return specific errors

Example: lookup_error_code("EINVAL") shows all syscalls that can return EINVAL
